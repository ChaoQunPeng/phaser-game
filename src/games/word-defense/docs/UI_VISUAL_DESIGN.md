# 战斗主界面视觉基线

采用「手绘文字战棋」方向：汉字作为棋子形象、纸张底色、整齐网格、轻微手绘墨线与克制国风。当前仅实施 P1 战斗主界面，不改合集导航、其他游戏、玩法数值或核心架构。

## 当前呈现

- 米色纸面，以少量固定纤维线条表达纸张质感；不使用整屏噪点或大幅背景图。
- 8×8 规则棋盘，沙色路径和小箭头明确移动方向，「入」「守」标记端点。
- 我方棋子使用青绿色墨线、纸色底座；敌方使用朱红墨线与浅红底座，短血条放在棋子上方。
- 毛笔汉字是棋子主体，不添加人物头像、品质标签或覆盖主文字的复杂数值。
- 上方为城防、波次和主要战斗操作；下方为四张兵种纸卡、选中信息与移除操作。
- 当前兵种使用小号说明区分射程、单攻和群攻；选中兵种有青色底和朱砂角标，选中地图单位有四角墨线。
- 暂停、胜利和失败使用简洁纸笺覆盖层，不遮挡上方继续/重开按钮。

## 主题与实现边界

`ui/theme.ts` 管理颜色、字体、字号、主要尺寸、间距、按钮视觉状态与动效时长，以及纸面/纸卡绘图函数。`ui/PaperButton.ts` 共用正常、选中、主操作和禁用状态，并处理真实命中区域。

标题和棋子采用本地 `BattleBrush` 字体，来源、版权及字形扩展方式见 `assets/README.md`。正文采用系统中文字体，优先保证信息阅读。

`GridView` 绘制网格与选中状态，`EntityViews` 按稳定 ID 复用棋子。`BattleHud` 只读取快照，`BattleScene` 转发命令并消费攻击通知，不计算生命、伤害或波次。

落子采用 180ms 缩放，攻击汉字轻推 3px，轨迹约 150ms 淡出，受击汉字短暂移位和变淡。动画仅作用于渲染对象，不改变逻辑坐标或攻击时钟。合成与英雄视觉留到对应功能阶段实现，未增加空界面或模拟业务。

## 本轮验证

- TypeScript 类型检查通过。
- 浏览器检查手机与桌面布局，完整画布未出现文字重叠或内容溢出。
- 实际点击检查兵种切换、免费落子、单位选中、移除、按钮启用/禁用、开始和重开。
- 实际战斗中检查敌方文字棋子、短血条、攻击墨线与失败纸笺；控制台无错误/警告。
- 修正 Container 输入原点与纸卡左上角绘制坐标的差异，保证按钮完整可见区域可点击。
- 本轮未运行自动化战斗测试或生产构建；玩法核心未修改。
