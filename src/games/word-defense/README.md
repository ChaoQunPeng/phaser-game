# 文字合成塔防

## 说明

结合塔防和自走棋的玩法（就是王国保卫战和金铲铲之战这两种）

## 游戏设计与玩法

1、地图8*8，每格1*1
2、怪物是固定一组或两个（后续可能有三个）路径，到达要防守的目标点时，玩家扣血
3、玩家可以选择、弓、枪、刀、骑（以下统称为基础单位），然后可以合成各种英雄，历史级（历史上出现的，但是叫历史级很难听，帮我想个名字），神话级
4、每次游戏会爆各种装备（常规的，然后结合其英雄背景，产出对应的武器，武器需要集齐碎片才能合成，普通的武器不用碎片）
5、玩家按一定频率获得金币，金币可以刷新召唤池，一般10秒刷新一次，
6、召唤池是玩家控制的各种对象，需要花费金币才能召唤，基础单位和英雄，也能刷出一些道具（装备、回血、道具等）
7、召唤池容量目前5个
8、还有各种主动技能和被动技能给到玩家，玩家可以用此影响游戏
9、基础单位游戏中可以合成，每2个合成1个，升1级，最多升到5级
10、英雄单位游戏内只能合成一次，然后就是根据击杀的怪物升级，目前最多5级
11、召唤池手动刷新
12、单位放置好后无法移动，但是可以移除
13、合成消耗单位。例如两个1级刀，合成后只有一个2级刀
14、常规模式20波，一波比一波强，坚持到20波就算大胜利，有大奖励

## 游戏设定

弓：远程攻击（5范围，单体）
枪：穿刺攻击（4范围，范围伤害）
刀：近战攻击（1范围，单体）
骑：近战攻击（3范围，范围伤害）
